## Post
Over 80% less time.

That's what one small Figma plugin did for a task I kept running into: localization.

Every time an interface needed another language, the work happened outside Figma. Copy, paste, check, fix, repeat.

So in June I designed and built a plugin myself, in HTML, CSS and JavaScript. Now designers can localize screens right inside Figma.

Localization time dropped by over 80%, and translations stayed consistent from screen to screen.

I'm a designer first. But one of the most useful things I built this year started with a simple question: why am I still doing this by hand?

What's one repetitive task in your work you'd automate tomorrow if you could?
