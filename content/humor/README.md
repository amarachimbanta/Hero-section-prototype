# Humor screenshots

- `swipe/`: screenshots of other people's posts that took off. Name them `YYYY-MM-DD-<author-or-topic>.png`.
- `mine/`: screenshots of my own humor posts, ideally a day or two after posting so the reaction and comment counts show.

Get the counts in the shot (reactions, comments, reposts) so they can be logged. Then run `/humor-post` (or just say "log my new screenshots") and they'll be analysed and added to `content/humor.md`.

If this repo is public, crop or blur other people's names and faces before committing.
