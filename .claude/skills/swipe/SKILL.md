# Swipe

## Read first
1. `content/swipe.md`: the anatomy, structures, swipe log, my posts, gaps.
2. `content/humor.md`: if the screenshot is a humor post, it goes there instead.

## Log a screenshot
Use for new images in `content/swipe/others/`, `content/swipe/mine/`, `content/humor/swipe/`, `content/humor/mine/`, or one I attach in chat.
1. **Sort it**: funny post, goes to `content/humor.md` (follow `/humor-post` Mode A). Anything else, goes to `content/swipe.md`.
2. If I attached it in chat, save it to the right folder as `YYYY-MM-DD-<author>-<topic>.png` (others) or `YYYY-MM-DD-<topic>.png` (mine). If you can't save it, log the file as `(chat, not saved)` and tell me.
3. Open the image and transcribe the first line exactly.
4. Score it against the 9 parts of the **Anatomy**. Note which parts it hits.
5. Name its **structure**. If it's a new shape, add it under *Structures that work* with the step-by-step outline and a **design version to try** (a template for my design work, with blanks where my real details go; never fill blanks with invented facts).
6. Counts (reactions, comments, reposts, age) only if visible. Note the comment-to-reaction ratio: above ~20% means people replied with their own story.
7. Write *Why it worked* in plain sentences. Be specific: quote the lines that do the work.
8. Add the row to *Swipe log* (others) or *My posts* (mine).

## Compare: what's missing in mine
Run whenever a new screenshot of mine is logged, or when I ask.
1. Line up my posts against the swipe log: anatomy scores, hook style, length, structure, visual, comment ratio.
2. Write the **top 3 gaps**, most important first. For each: what the winners do, what my post did instead (quote it), and the exact fix for my next post.
3. Replace the *What's missing in mine* section with this. Keep it short and blunt.
4. Once there are 5+ rows total, update *Patterns across the winners*.

All writing here follows `content/human-writing.md` too.
