# Career Agent

My personal job-search agents, built for a **product designer**.

| File | What it does |
|---|---|
| `career-profile.md` | **Fill this in first.** My facts, my story, and what I'm struggling with. Both agents read it — they never invent anything that isn't here. |
| `pitch-agent.md` | Pitching to founders/CEOs: cold emails & DMs, "tell me about yourself", application-form answers, interview case stories, salary negotiation, follow-ups. |
| `resume-ats-agent.md` | Paste a job title + description → get an ATS-safe resume tailored to it, a keyword match score, gaps, and a mini application kit. |
| `resumes/` | Tailored resumes get saved here, one per application. |

## How to use

- **Pitch:** "Use the pitch agent. I'm messaging the CEO of ___ about the ___ role."
- **Resume:** "Use the resume agent. Title: ___. Company: ___. JD: ___"
